### 追加：找到真正的控制点 —— 移动规格顺序（2026-10-08 第 5 轮）

用户在评审时问：「为什么不能每次都规格1=颜色，还要检测跑两遍？」—— 追下去找到了根治手段。

**先澄清一点**：错位**不是标签错**。我们写进 dy_spec.xlsx 的列序是稳定的，
页面读回也一直是「颜色=规格类型1（30 值）、尺码=规格类型2（4 值）」。
会变的是**两个组在规格管理器里的显示顺序** —— 智能填写助手异步创建这两组，谁先落地谁在上面，
而「仅支持第一组规格添加规格图」认的是**显示位置**。

**决定性实验**（在本条草稿上做，可逆）：

```
BEFORE   = [规格类型1 带图=true, 规格类型2 带图=false]
点「规格类型2」的上移 → 平台弹窗 → 点「确定」
AFTER1   = [规格类型2 带图=true, 规格类型1 带图=false]   ← 能力跟着位置走了
点「规格类型1」的上移 → 确认
AFTER2   = [规格类型1 带图=true, 规格类型2 带图=false]   ← 完全复位
```

弹窗原文就是官方答案：

> 「仅第一组规格支持添加规格图片，若确认移动该规格项顺序，原规格图片将被清空，需重新上传」

① 能力确实跟着位置走 → **可以强制搬**；② 移动会清空已有规格图 → **必须在传图之前搬**
（正好是我们流程里 ⑦ 之后、⑧ 之前）。

三个必须记住的实现细节：

1. **必须 Playwright 真实点击**「上移」：原生 `el.click()` 也会弹出确认框，但点了不生效
   （所以第一版实验「点了没事发生」，还以为不行）。
2. 「上移」控件的 class 是 CSS Modules 哈希、text 精确匹配还会命中多个 → **按组头的 y 定位**
   （实测两者 y 差 < 46px）。
3. 弹窗要点「确定」（`.ecom-g-modal-root` 里的 `确定` 按钮）。

→ ⑧ 现在先 `ensureSpecImageGroup`：读组 → 不对就上移 + 确认 → 读回确认；搬不动才
`spec_image_group_mismatch` 中止。**不再是「掷硬币 + 重跑」**。

### 追加：两处收紧（同轮）

**a) 硬保险从「至少一行点中」收紧为「必须全部行成功」才点「确定」。**
第 4 轮实跑暴露：那轮出图组其实是对的（`moved: false`），失败是**第 1 行成功、2-9 行的下拉
根本没打开**（`clicked:false`）；因为「至少一行点中」放行了，于是带着半残赋值点了「确定」→
6 处「请上传规格图」+ `价格填写进度` 76%。

**b) 关抽屉里的残留下拉别用 Escape** —— Escape 有时会连**抽屉**一起关掉，正是 2-9 行打不开的
嫌疑。改成「点抽屉内部（`th`）」，并在每行前 `drawerAlive()` 探测；抽屉真被关了就直接整轮判失败。

### 暴露二：**一个规格值只能挂一张图**（硬约束 4）

源数据 24 张规格图按「颜色×尺寸」出（`kaqi-30x30.png` …），但抽屉只列第一组规格（颜色-片数）的 18 个值。
第一版改动是「投影到 dims[0]、每张图挂上共现的值」→ **必然撞死**：

```
图0 占到 卡其色-2片/5片/10片  → ok
图1/2/3 再要同样的 3 个值      → clickedAny=false, missed=['卡其色-2片']
                                  （下拉能打开、值不在里面；3 轮现象完全一致）
```

**根因**：平台支持「一张图 → 多个值」，**不支持「一个值 → 多张图」**——
值被占用后就从其它行的下拉里消失了。所以 24 张图最多只能用 18 张，同色 4 张只能留 1 张。

修法（`build_product.py`）：投影到 `dims[0]` + **每个值只留给它遇到的第一张图**，
并把用不上的图**响亮报出**、写进 `product.json.spec_image_note.dropped`：

```
★ 规格图沿多维度变化（规格类型1×规格类型2）→ 投影到第一组规格「规格类型1」：6 张图共挂 18 个值
   ⚠ 一个规格值只能挂一张图 → 另有 18 张图用不上（值已被先出现的图占用）：spec_06.png, …
```

跑完 ⑧ 的读回：`ok=true, rows=6, confirmed=true`，6 行全中（每行 3 个值）。
> 这条约束**只影响「图沿多维变化」的商品**；PE3/GPVC-001/ZDT-001/002（图只随单一维度变）走原路径，不受影响。
